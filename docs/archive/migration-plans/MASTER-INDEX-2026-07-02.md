## 5. Cómo mantener este índice

**Cuándo actualizar este archivo:**
- Cuando se crea un documento nuevo → agregar a la tabla correcta
- Cuando un documento se vuelve irrelevante → marcar con ❌ o eliminar
- Cuando el estado de un documento cambia → actualizar la tabla de estado

**Regla:** Si un documento no está aquí, no existe para el equipo.

**Cadencia:** Revisar este índice cada vez que se haga un sprint de documentación o cuando alguien nuevo se una.
