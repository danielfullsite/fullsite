### N2 · `POS_FALLBACK_PIN` es una llave maestra cross-tenant 🔴 P0 para Cliente #2
```
api/pos/pin/route.ts:133-136
const fallback = process.env.POS_FALLBACK_PIN
if (fallback && pin === fallback) return respond({ id:'admin', name:'Admin', role:'admin' }, clientId, ...)
```
No se valida `clientId` contra nada: quien conozca ese PIN entra como **admin de cualquier
restaurante** y se lleva un shift token firmado. Existe en producción desde hace 74 días.
Con un solo cliente es una comodidad; con Cliente #2 es una brecha.
