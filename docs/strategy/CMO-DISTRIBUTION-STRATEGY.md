## 1. Diagnóstico

**El problema central:** Google interpreta "Fullsite" como "full site" (sitio web completo). No hay autoridad de búsqueda. No hay presencia digital. No hay contenido indexado.

**Lo que tenemos a favor:**
- 903 días de datos operativos reales ($73.7M MXN)
- Day 0 cutover verificable — no es vaporware
- 30 agentes IA corriendo en producción
- LOI con Grupo Galería (Dunkin, Carl's Jr, BWW, IHOP)
- Integración Rappi firmada
- Historia fundacional poderosa: 23 años, opera su propio restaurante, reverse-engineered el sistema líder

**Competencia en search (México):**

| Keyword | Competidor dominante | DA estimado | Dificultad |
|---|---|---|---|
| software para restaurantes | SoftRestaurant, Poster POS | 30-45 | Media |
| POS restaurantes México | SoftRestaurant, Aloha | 35-50 | Media-Alta |
| sistema punto de venta restaurante | SoftRestaurant, iZettle/Zettle | 40-55 | Alta |
| inventario restaurante software | SoftRestaurant, MarketMan | 25-35 | Media |
| KDS cocina digital | Casi nadie | 10-15 | Baja |
| cómo reducir food cost restaurante | Blogs genéricos | 15-25 | Baja |
| Wansoft alternativa | Nadie | 5 | Muy Baja |

**Oportunidad:** El mercado mexicano de software para restaurantes tiene SEO débil. SoftRestaurant domina pero su contenido es anticuado. No hay content marketing sofisticado. El espacio de "IA para restaurantes" está vacío.

## 5. Comparativas — Páginas de Batalla

### 5.1 Estructura de cada página /vs/

Cada comparativa debe tener:
1. H1: "Fullsite vs [Competidor]: Comparativa completa [año]"
2. Tabla lado a lado de features
3. Pricing comparison
4. "Para quién es mejor [Competidor]" (honestidad = credibilidad)
5. "Para quién es mejor Fullsite"
6. Testimonial o dato real
7. CTA: "Migra de [Competidor] a Fullsite en 30 minutos"

### 5.2 Comparativas prioritarias

**Fullsite vs Wansoft** (HACER PRIMERO — semana 2)
- Keyword: "alternativa a Wansoft", "Wansoft problemas"
- Ángulo: "20 años vs 20 meses de desarrollo"
- Datos: 822 stored procedures → 30 agentes IA
- Pain point: .NET 4.5 de 2007, SQL Server local, sin API HTTPS
- CTA: "Migramos 522 platillos de Wansoft en 30 minutos"

**Fullsite vs SoftRestaurant** (semana 3)
- Keyword: "SoftRestaurant alternativa", "SoftRestaurant opiniones"
- Ángulo: SoftRestaurant es el legacy institucional, Fullsite es el futuro con IA
- Diferenciadores: IA, cloud-native, instalación 30 min vs días
- Competitor intel: SoftRestaurant cobra licencias por terminal + soporte anual

**Fullsite vs Toast** (mes 2)
- Keyword: "Toast POS México", "Toast alternativa México"
- Ángulo: Toast no opera en México, Fullsite sí. Toast es gringo, Fullsite entiende la operación mexicana (propinas, facturación CFDI, división de pagos estilo MX)
- Diferenciador: Fullsite tiene IA operativa, Toast es un POS con reportes

**Fullsite vs Poster POS** (mes 2)
- Keyword: "Poster POS opiniones", "Poster POS México"
- Ángulo: Poster es genérico (retail + restaurantes), Fullsite es 100% restaurantes
- Diferenciador: Fullsite tiene KDS, recetas, food cost automático

**Fullsite vs Aloha NCR** (mes 3)
- Keyword: "Aloha POS alternativa"
- Ángulo: Aloha es enterprise legacy, caro, lento de implementar
- Diferenciador: Fullsite se instala en 30 min, Aloha tarda semanas

**Costo:** $0
**Esfuerzo:** Bajo (2-3 horas por página, datos ya los tienes)
**Impacto:** Alto (captura tráfico de gente buscando alternativas, alta intención de compra)
